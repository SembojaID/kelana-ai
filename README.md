# KelanaAI - Travel Assistant API ✈️🌍

KelanaAI adalah aplikasi asisten perjalanan berbasis REST API yang dibangun menggunakan Python dan FastAPI. Aplikasi ini dirancang untuk membantu pengguna merencanakan perjalanan, menghitung anggaran liburan, menentukan kategori perjalanan, serta memberikan rekomendasi tempat wisata dan moda transportasi.

Proyek ini merupakan bagian dari **Alkademi - AI Native Software Engineer Bootcamp**.

## 🚀 Fitur Utama (Session 3)
*   **Trip Recommendation Engine:** Menghitung anggaran harian dan menentukan kategori liburan (Backpacker, Standard, Luxury).
*   **REST API Layer:** Menggunakan FastAPI untuk melayani permintaan data dalam format JSON.
*   **Auto-generated Documentation:** Dilengkapi dengan Swagger UI interaktif.
*   **Data Retrieval:** Menyediakan daftar rekomendasi tempat dan transportasi.

## 🛠️ Teknologi yang Digunakan
*   **Bahasa Pemrograman:** Python 3
*   **Framework Web:** FastAPI
*   **Server:** Uvicorn
*   **Validasi Data:** Pydantic
